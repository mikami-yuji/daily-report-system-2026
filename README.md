## ✨ 主な特徴・メリット

- 📊 **エクセル原本の完全保護**: 既存のエクセルファイル（`.xlsm`）を直接読み書き。数式・マクロ・フォント・罫線・セル書式を100%保持したまま安全に運用。
- ☁️ **Salesforce風モダンUI**: 直感的なサイドバーナビゲーション、カードレイアウト、状況に応じた動的フォーム切り替え。
- ⚡ **超高速レスポンス（マルチレイヤキャッシュ）**: 共有フォルダ上の大容量エクセルをSQLiteキャッシュデータベースへインデックス化し、ミリ秒単位の超高速表示・検索を実現。
- 📶 **オフライン・瞬断セーフティ（一時退避キュー）**: 社内LANの瞬断や移動中（圏外）でもブラウザ内に日報を安全に保護。復帰時にエクセルへ自動再同期。
- 🎨 **企画課デザインビューア連携**: 社内デザイン管理システムとAPI連携し、依頼案件の自動補完、全PDF（枝番履歴）タブ切り替え閲覧、カンプ画像プレビューに対応。
- 🎯 **営業活動の可視化と目標支援**: 月間200点目標ペースメーカー、重点顧客放置防止アラート、全営業メンバー活動点数表を搭載。
- 🔄 **社内サーバー経由のワンクリック自動アップデート**: 新バージョンを自動検知し、安全なSHA256検証・自動再起動で最新環境へアップデート。

## 🛡️ 堅牢性・データ保全アーキテクチャ

```mermaid
graph TD
    User([営業担当者 / ブラウザ]) <-->|Next.js 16 SPA (Port 8001)| ServerExe[DailyReportServer.exe]
    ServerExe <-->|FastAPI REST API| LocalEngine[SQLiteローカルキャッシュ engine]
    ServerExe <-->|openpyxl / pandas| ExcelShared[(共有エクセル .xlsm)]
    ServerExe -.->|非同期 BackgroundTasks| Backup[(backup/ 30日自動世代管理)]
    ServerExe -.->|回線瞬断時| LocalQueue[(ローカル一時退避キュー)]
    ServerExe <-->|Proxy API| ViewerServer[(企画課ビューア 192.168.1.5)]
```

1. **Excel原本完全保護ガード**:
   - 新規保存時は直前の行からセル書式（フォント、罫線、色、表示形式）を自動継承して行追加。
   - シート構造や数式、マクロを完全に保護。
2. **アトミック保存 & 指数バックオフ自動リトライ**:
   - 一時ファイルへ書き込み・整合性検証を行った後に原本ファイルをアトミック置換。
   - 他者がファイルを開いている場合でも、指数バックオフアルゴリズムによる自動リトライを実行し書き込み失敗を防止。
3. **自動非同期バックアップ & 30日世代管理**:
   - 日報保存時に、エクセル同階層の `backup/` フォルダへタイムスタンプ付き複製を自動作成。
   - 30日経過した古いバックアップファイルを自動クリーンアップ。
   - 最低世代保証 (`min_keep`) およびタイムスタンプのない原本ファイルを絶対に削除しない安全ガードを搭載。
4. **プロセス内排他制御 & 楽観的ロック (OCC)**:
   - 複数画面・複数端末からの保存要求をスレッドロックで安全に直列化。
   - 編集開始時と保存直前のセル値を照合し、競合時は `409 Conflict` で上書き消失を完全にブロック。
5. **マルチレイヤキャッシュ (SQLite + Memory)**:
   - ファイル更新日時（`st_mtime`）をミリ秒単位で監視。
   - 変更時のみ差分再構築を行い、通常アクセス時はローカルSQLiteから瞬時に応答。

## 🚀 一般ユーザー向け：システム起動方法

一般ユーザー様は、複雑な環境構築を行うことなく以下のいずれかの方法ですぐに使用できます。

### 方法1: 配布用実行ファイルから起動（推奨）

1. 配布されたフォルダ内の **`DailyReportServer.exe`** をダブルクリックします。
2. 黒い画面（コマンドプロンプト）が立ち上がり、自動的にブラウザが開きます。
3. ブラウザで日報システム画面（`http://localhost:8001`）が表示されます。

> [!IMPORTANT]
> **黒い画面（コマンドプロンプト）は閉じないでください**  
> 黒い画面はシステムの裏側で動いているエンジンです。使用中は閉じずに最小化（「ー」ボタン）にしておいてください。

### 方法2: VBScript / バッチファイルから起動

- **`営業日報システム起動.vbs`** をダブルクリック  
  または
- **`start_app.bat`** をダブルクリック

## 💻 開発環境セットアップ手順 (ルール11準拠)

開発やデバッグ、機能改修を行うエンジニア向けの完全なセットアップ手順です。

### 1. 前提ソフトウェア要件

- **OS**: Windows 10 / 11 (64bit)
- **Node.js**: `v18.0.0` 以上 (推奨: `v20.x` LTS)
- **Python**: `3.10` 以上 (推奨: `3.13`)
- **Git**: インストール済みであること

### 2. リポジトリのクローン

```powershell
git clone <repository-url> daily-report-system-2026
cd daily-report-system-2026
```

### 3. バックエンドのセットアップと起動

```powershell
# バックエンドディレクトリへ移動
cd backend

# Python 仮想環境の作成（推奨）
python -m venv venv
.\venv\Scripts\Activate.ps1

# 依存パッケージのインストール
pip install -r requirements.txt

# 設定ファイルの準備（初回のみ）
if (-not (Test-Path "config.json")) {
    Copy-Item "config.example.json" "config.json"
}

# バックエンドサーバーの起動 (Port: 8001)
python main.py
```
*※ `http://localhost:8001` でFastAPIサーバーが起動し、Swagger UI（`http://localhost:8001/docs`）にアクセス可能です。*

### 4. フロントエンドのセットアップと起動

別のターミナルを開き、以下を実行します：

```powershell
# フロントエンドディレクトリへ移動
cd frontend

# npm パッケージのインストール
npm install

# 開発サーバーの起動 (Port: 3000)
npm run dev
```
*※ `http://localhost:3000` でNext.js開発サーバーが起動します。開発環境下ではAPIリクエストは自動的に `http://localhost:8001` へプロキシされます。*

## ⚙️ システム管理者向け設定仕様

### `config.json` の設定仕様

システムルートの `config.json` でエクセルファイルの格納場所やネットワークパスを指定します。

```json
{
  "excel_dir": "\\\\Asahipack02\\社内書類ｎｅｗ\\01：部署別　営業部\\02：営業日報\\2026年度",
  "update_dir": "\\\\Asahipack02\\社内書類ｎｅｗ\\01：部署別　営業部\\02：営業日報\\2026年度\\_app_update",
  "port": 8001
}
```

> [!CAUTION]
> **バックスラッシュ（`\`）のエスケープについて**  
> JSONの仕様上、ネットワークパス（UNCパス）やWindowsパスの区切り文字は必ず **`\\`（二重バックスラッシュ）** で記述してください。一重で記述するとJSONパースエラーとなりシステムが起動しません。

### 新年度（年度変更時）の切り替え手順

1. 共有サーバー上の新年度フォルダに、前年度またはひな形のエクセルファイル（例: `日報_2027.xlsm`）を準備します。
2. `config.json` の `"excel_dir"` のパスを新しい年度フォルダへ書き換えます。
3. `DailyReportServer.exe` を再起動すると、自動的に新年度のエクセルファイル群が認識されます。

## 🔧 トラブルシューティング

### 1. 保存時に `PermissionError` が発生する
- **原因**: 対象のエクセルファイル（`.xlsm`）を、自分または他のユーザーが直接Excelソフトで開いて作業しています。
- **対策**: Excelソフトで開いているファイルをすべて閉じてから、再度保存ボタンを押してください。

### 2. 画面が真っ白、または「接続できません」と表示される
- **原因**: バックエンドサーバー（黒い画面）が終了しているか、社内ネットワーク（VPN）が切断されています。
- **対策**:
  1. `DailyReportServer.exe` または `営業日報システム起動.vbs` を再起動してください。
  2. 共有サーバー（`\\Asahipack02`）へのネットワーク接続状態を確認してください。

### 3. 「他のユーザーにより内容が更新されています (409 Conflict)」と表示される
- **原因**: 編集画面を開いている間に、上長や他の担当者が該当の日報を更新しました（上書き防止ガード作動）。
- **対策**: 画面を更新（F5）して最新データを確認した上で、改めて編集・保存を行ってください。

### 4. 入力した日報がエクセル原本に反映されていない
- **原因**: 回線瞬断等により「一時退避キュー（未送信）」に保存されている状態です。
- **対策**: 画面左下の `☁️ オフライン (○件未送信)` をクリックして手動送信するか、安定したネットワーク環境に再接続してください。自動的にエクセルへ同期されます。

### 5. 企画課ビューアの画像・PDFを開くとエラーになる
- **原因**: ビューアサーバー（`192.168.1.5`）の認証が切れているか、パスコードが未設定です。
- **対策**: 「設定」画面で「企画課デザインビューア連携」のパスコードを入力し、「接続テスト & 保存」を行ってください。
