# 営業日報システム (Daily Report System)

エクセルベースの日報を、モダンなWebインターフェースで管理できるシステムです。Salesforceのような使いやすいUIで、日々の活動報告やデザイン依頼の管理を効率化します。

## ✨ 特徴

- 📊 **エクセル連携**: 既存のエクセルファイル（`.xlsm`）を直接読み書き。関数やマクロを保持したまま運用可能。
- ☁️ **Salesforce風UI**: 直感的でプロフェッショナルなデザイン。サイドバーナビゲーションやカード型レイアウトを採用。
- 🔍 **高度なデザイン検索**:
    - デザインNo.、得意先、デザイン名、種別でのクロス検索
    - 得意先ごとのデザイン種別動的フィルタリング
    - 進捗状況の可視化（色分けバッジ）
    - 関連する活動履歴の時系列表示
- 📈 **データ分析**: 月ごとの訪問数・電話数、重点顧客への活動状況をグラフで可視化。
- 📂 **ファイル管理**: ブラウザから直接エクセルファイルをアップロードして切り替え可能。
- 💻 **PC・タブレット対応**: パソコンやタブレットのブラウザ環境で快適に入力・表示できる最適化デザイン。
- ⚡ **高速な動作**: Next.js 16 (App Router) と Tailwind CSS によるモダンな実装。
- 🛡️ **自動バックアップ & 世代管理**: 日報保存時に `backup` フォルダへ自動複製。最新50世代を維持し、30日経過した古いバックアップを自動整理。
- 🔒 **原本エクセルの完全保護**: 原本ファイルを絶対に誤削除しない三重の安全防護壁（ディレクトリ検証・タイムスタンプ必須化・最新5件の永久保護）を搭載。
- ⚡ **安全な保存 & 自動リトライ**: 一時ファイル経由の破損検証とアトミック置換、ファイルロック時の指数バックオフ付き自動リトライにより保存失敗を防止。

## 🚀 アプリの起動方法

環境に合わせて以下のいずれかの方法で起動してください。

### 🏠 通常の起動（家のPCや2回目以降）

**`start_app.bat` をダブルクリックしてください。**

- バックエンドとフロントエンドが自動的に起動します。
- ブラウザが開き、`http://localhost:3000` にアクセスできます。

### 🏢 会社PCでの初回セットアップ

社内PCで初めて作業する場合のみ、以下の手順で設定を行ってください。

1. プロジェクトフォルダを開く
2. **`setup_for_company.ps1` を右クリックして「PowerShellで実行」を選択**
   - 必要な設定ファイル（`config.json`）が自動作成され、社内ネットワークパスが設定されます
   - 設定完了後、アプリが起動します

> **Note**: 2回目以降は、上記の「通常の起動」と同じく `start_app.bat` で起動できます。

### ⚠️ 手動で起動する場合（バッチファイルが動かない時）

もしバッチファイルでうまく起動しない場合は、以下のコマンドで個別に起動してください。

#### 1. バックエンド
```powershell
cd backend
python main.py
```

#### 2. フロントエンド（別のターミナルで）
```powershell
cd frontend
npm run dev
```

## 🔧 トラブルシューティング

### API 500 エラーが発生する場合

バックエンドの`config.json`が正しく設定されているか確認してください。ネットワークパスではなく、ローカルの絶対パスを指定する必要があります。

### 無限ループで読み込み中になる場合

ブラウザのキャッシュをクリアしてページをリフレッシュしてください。最新版では修正済みです。

### ポートが使用中の場合

- バックエンド: デフォルトはポート8001
- フロントエンド: デフォルトはポート3000

他のプロセスが使用している場合は、該当プロセスを停止してください。

## 📁 プロジェクト構成

```
daily-report-system/
├── backend/              # Python FastAPI バックエンド
│   ├── main.py          # メインAPIサーバー
│   ├── excel_schema.py  # Excel列定義・マッピング一元管理スキーマ層
│   ├── excel_io.py      # 安全なファイル保存・読み込み・リトライ機構
│   ├── cache.py         # キャッシュ＆バックアップ世代管理
│   ├── routes_reports.py# 日報CRUD・承認・コメントAPI
│   ├── routes_stats.py  # 統計・月次集計・ダッシュボードAPI
│   ├── tests/           # 単体テスト・回帰テスト（全19テスト）
│   └── requirements.txt # Python依存関係
├── frontend/            # Next.js フロントエンド
│   ├── src/
│   │   ├── app/         # App Router（各画面ページ）
│   │   ├── components/  # 共通UIコンポーネント
│   │   └── lib/         # APIクライアント
│   └── package.json
├── daily_report_template.xlsm  # エクセルデータファイル
└── 使い方ガイド.md              # 詳細な使い方
```
